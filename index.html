주니 마커

화면을 캡처하고 번호·도형·직선·화살표·형광펜·글자·모자이크를 넣어 바로 복사하거나 저장하는 Windows 프로그램입니다.

다운로드

Windows용 내려받기
버전 1.10 · 2026-11-27 · 약 38MB · Windows 10/11 64비트 · 파이썬·인터넷 연결 필요 없음

설치 (1분)

  1. 받은 zip 파일을 우클릭 → 모두 압축 풀기
  2. 풀린 폴더의 install.bat 더블클릭 (로그인 때 자동 시작 여부를 물어봅니다)
  3. 바탕화면의 주니 마커 캡처를 더블클릭하거나 Ctrl Alt J를 누르세요

지울 때는 같은 폴더의 uninstall.bat을 실행하세요.

사용

  • Ctrl Shift A로 캡처 시작 → 영역 드래그 → 번호·사각형·동그라미·직선·화살표·형광펜·글자·모자이크
  • 도형 안쪽을 원하는 면색(흰색·노랑 등, 직접 고르기 가능)으로 채우기 · 개인정보는 모자이크로 가리기
  • 무료 한글 글꼴 9종 포함, 글씨체와 굵게 선택 · 넣은 글자는 더블클릭해서 다시 고치기 · 번호 크기 선택과 나중에 변경
  • 선택 도구로 도형·화살표·직선·번호·글자를 눌러 고르고 끌어서 옮기기, Delete로 지우기, Ctrl Z로 되돌리기
  • Ctrl C 복사 / Ctrl S 저장(저장하면 자동으로 종료) / Esc 취소
