# 주니 마커

화면을 캡처하고 번호·도형·화살표·형광펜·글자를 넣어 바로 복사하거나 저장하는 Windows 프로그램입니다.

- 다운로드 페이지: https://specialjun12-commits.github.io/juni-marker/
- 설치 파일: [JuniMarker_v1.10_Setup.zip](https://github.com/specialjun12-commits/juni-marker/releases/download/v1.10/JuniMarker_v1.10_Setup.zip) (버전 1.10, Windows 10/11 64비트, 파이썬·인터넷 필요 없음)

## 설치
1. zip 파일 우클릭 → 모두 압축 풀기
2. 풀린 폴더의 `install.bat` 더블클릭
3. 바탕화면의 「주니 마커 캡처」 더블클릭 또는 `Ctrl+Alt+J`

지울 때는 같은 폴더의 `uninstall.bat`을 실행하세요.

## 파일 확인
`certutil -hashfile JuniMarker_v1.10_Setup.zip SHA256` 결과가 아래 값과 같아야 합니다.

```
3c74be17f74fbf457b846a933e29f4bc2ece8816b06e08faafb73551803ac11d
```

이 저장소에는 다운로드 페이지만 있고, 프로그램은 릴리스 파일로 배포합니다.
아이콘 일부는 [Lucide](https://lucide.dev)(ISC 라이선스)를 사용했습니다.
